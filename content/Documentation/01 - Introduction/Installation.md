## 1	Installation Steps
1. Go to the [Github homepage](https://github.com/lucas0623/design-master-vba) of the add-in. Click the **Releases** button of the right hand side of the page.![[../../Z_System/Attachment/Pasted image 20250207145819.png]]
2. Download the .xlam file.![[../../Z_System/Attachment/{29640F2C-DC5D-4C8A-AD24-D9D736A97519}.png]]
3. Open Excel, go to `File>Option>Add-ins`, and click `go` in the Manage option. ![[../../Z_System/Attachment/{FFB33FCF-9C54-46EC-92C3-8BC3035799E8}.png]]
4. Click `Browse` and select the .xlam file downloaded.
5. A new ribbon tab named `Design master` tab should appear at the workbook. ![[../../Z_System/Attachment/{F4A5241A-9FD2-4EE0-84B4-DEF1512D8662}.png]]

## 2	FAQ
**Question**: An error message 'This file type is not supported in Protected View' pop up when I load the add-in. How to resolve it? 
![[../../Z_System/Attachment/Pasted image 20250207151329.png]]
**Answer**: Try Unlock the File by the following steps:
1. Locate the .xlam file in Windows Explorer.
2. Right-click the file and select "Properties."
3. If you see an "Unblock" checkbox under the "General" tab, check it and then click "OK."
![[../../Z_System/Attachment/{CBB86255-A8A4-4514-9EDC-92C0B6A6AA60}.png]]
